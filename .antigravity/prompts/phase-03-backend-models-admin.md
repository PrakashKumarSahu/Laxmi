# Phase 03: Backend Models & Admin

## Objective
Implement database schema and Django admin panels.

## Tasks
1. Write models in `services/models.py`, `products/models.py`, `projects/models.py`, `home/models.py`.
2. Write admin configurations with custom list displays, search fields, filters.
3. Run `python manage.py makemigrations` and `python manage.py migrate`.
