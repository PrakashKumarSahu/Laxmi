# Phase 02: Scaffolding & Docker

## Objective
Setup dependencies, configuration, and docker environment for the Django backend.

## Tasks
1. Add `djangorestframework`, `django-cors-headers`, `pillow` to `requirements.txt`.
2. Update `laxmi/settings.py` for CORS, INSTALLED_APPS, REST_FRAMEWORK settings, static & media root.
3. Create `Dockerfile` and `docker-compose.yml`.
