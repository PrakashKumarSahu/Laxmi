# Laxmi Electronics — Frontend

React + Vite SPA for the Laxmi Electronics and Electricals platform.

## Development

```bash
npm install
cp .env.example .env   # configure API URL if needed
npm run dev            # http://localhost:5173
```

## Production build

```bash
npm run build
```

> See the root `README.md` for the full project documentation and Docker setup.
